Legislative Co-sponsorship Networks

Network Analysis
Computational Methods
Legislative Politics
Network analysis of parliamentary collaboration patterns to understand cross-party cooperation and legislative influence
Published

November 5, 2023

Overview

This project applies network analysis methods to study patterns of legislative collaboration through bill co-sponsorship. By examining who works with whom in parliament, we gain insights into informal influence structures, cross-party cooperation, and the role of individual legislators in bridging partisan divides.

Research Questions

  • What structural patterns characterize legislative co-sponsorship networks?
  • Which legislators serve as bridges between parties?
  • How do network positions relate to legislative success and career advancement?
  • Do co-sponsorship patterns predict voting behavior?

Data & Scope

Legislative Bodies:

  • German Bundestag (17th-20th legislative periods)
  • European Parliament (7th-9th terms)

Data Collected:

  • Bill sponsorship and co-sponsorship records
  • Legislator attributes (party, committee assignments, tenure)
  • Bill outcomes (passage, amendment, rejection)
  • Vote records for validation

Network Construction:

Edges represent co-sponsorship ties weighted by:

  • Number of jointly sponsored bills
  • Temporal proximity of co-sponsorships
  • Bill importance (measured by media coverage)

Methodology

Network Metrics

Metric Description Application
Degree Centrality Number of co-sponsorship partners Overall collaboration activity
Betweenness Bridging position in network Cross-party broker identification
Clustering Local network density Factional structure detection
Modularity Community structure Party cohesion analysis

Analytical Approaches

  1. Descriptive Network Analysis
    • Visualization of network structure
    • Community detection algorithms
    • Temporal evolution of network properties
  2. Exponential Random Graph Models (ERGMs)
    • Testing hypotheses about tie formation
    • Controlling for structural dependencies
    • Estimating effects of legislator attributes
  3. Network Influence Models
    • Predicting legislative success from network position
    • Career trajectory analysis

Key Findings

  • Party Boundaries: Co-sponsorship networks are highly structured by party, but meaningful cross-party ties exist
  • Brokers: Legislators with high betweenness centrality tend to be policy specialists rather than party leaders
  • Success: Network centrality positively predicts bill passage, controlling for party and seniority
  • Gender Dynamics: Women legislators show higher rates of cross-party co-sponsorship
  • Committee Effects: Committee membership is a stronger predictor of co-sponsorship than ideological proximity

Code Example

library(igraph)
library(ggraph)

# Create co-sponsorship network
cosponsorship_net <- graph_from_data_frame(
  edges,
  vertices = legislators,
  directed = FALSE
)

# Calculate centrality measures
V(cosponsorship_net)$betweenness <- betweenness(cosponsorship_net)
V(cosponsorship_net)$degree <- degree(cosponsorship_net)

# Visualize
ggraph(cosponsorship_net, layout = "fr") +
  geom_edge_link(alpha = 0.1) +
  geom_node_point(aes(color = party, size = betweenness)) +
  theme_graph()
